# Tamghart l'Artisane

## Description

Tamghart l'Artisane est une plateforme dédiée à la valorisation de l’artisanat amazigh et du savoir-faire des femmes artisanes marocaines.

Le projet met en avant des créations artisanales authentiques à travers une interface moderne, élégante et immersive, inspirée de l’identité culturelle amazighe.

L’objectif est de faciliter la découverte des produits artisanaux tout en offrant aux artisanes un espace pour présenter leur travail et leur histoire.
